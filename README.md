# Haunted Village

A Halloween take on the Santa Tracker experience. One scrolling illustrated village, eight games, six animated shorts with tap-to-hear narration, a hidden-object hunt, a quiz, a dress-up, coloring pages, a song you compose that plays through the whole village, and a live Witch Tracker on October 31.

Everything is drawn and played in the browser. No build step. Open `index.html` or visit the GitHub Pages link.

Made for kids on an iPad. Add it to the home screen for a full-screen app.
